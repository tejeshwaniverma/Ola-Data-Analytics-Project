OLA Data Analytics Dashboard | Power BI, SQL & Excel
• Analyzed 66.5K+ ride bookings with a total booking value of approximately ₹23M to identify key business trends and performance metrics.
• Used Excel for data cleaning, including removing duplicates, handling missing values, and standardizing data.
• Used SQL to extract, filter, aggregate, and analyze booking, revenue, cancellation, and customer data.
• Built an interactive Power BI dashboard with 5 views: Overall, Vehicle Type, Revenue, Cancellation, and Ratings
• Analyzed 41.35K successful bookings and 18.67K cancelled bookings, with an overall cancellation rate of 28.04%.
• Compared performance across 7 vehicle types based on booking value, successful bookings, distance travelled, and ratings.
• Analyzed revenue by Cash, UPI, Credit Card, and Debit Card payment methods.
• Analyzed customer and driver ratings, with ratings ranging from approximately 3.98 to 4.01 across vehicle types.
• Created interactive KPI cards, charts, tables, slicers, and date filters to present insights clearly and support data-driven decision-making.
• Tools: Power BI, SQL, Microsoft Excel.

This project demonstrates skills in data cleaning, data analysis, SQL querying, data visualization, dashboard development, and business insight generation.
