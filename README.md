OLA Data Analytics Project

An end-to-end Ola Data Analytics Project focused on analyzing ride booking data to uncover trends in bookings, revenue, cancellations, vehicle performance, and customer behavior.

🔍 Key Analysis
-Booking and ride status analysis
-Customer and driver cancellation analysis
-Revenue and ride distance analysis
-Vehicle type performance comparison
-Customer and driver rating analysis
-Ride trends and business insights
🛠️ Tools Used

SQL | Python | Microsoft Excel | Power BI

This project demonstrates skills in data cleaning, data analysis, SQL querying, data visualization, dashboard development, and business insight generation.
