# Ola-Data-Analytics-Project
OLA Data Analytics Project using SQL and Power BI. This project analyzes ride bookings, cancellations, vehicle types, customer and driver ratings, payment methods, ride distance, and booking revenue. It includes SQL queries and views to answer key business questions and Power BI visualizations to generate meaningful insights from the data.
